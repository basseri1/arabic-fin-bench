```
قرار مجلس الوزراء رقم (11) لسنة 2019
بشأن تنظيم إجراءات منح تأشيرات الدخول للأجانب

المادة (1): يُعمل بأحكام هذا القرار في شأن تنظيم إجراءات منح تأشيرات الدخول للأجانب.

المادة (2): تُمنح تأشيرات الدخول للأجانب وفقاً للشروط والضوابط التالية:
```
#### Conditions and Controls for Granting Entry Visas to Foreigners
```markdown
| Condition/Control | Description |
|-------------------|-------------|
| تقديم طلب التأشيرة | يجب على الأجنبي تقديم طلب التأشيرة إلى السفارة أو القنصلية المختصة |
| استيفاء البيانات | يجب أن يكون الطلب مستوفياً لجميع البيانات والمعلومات المطلوبة |
| إرفاق الوثائق | يجب إرفاق جميع الوثائق والمستندات اللازمة بالطلب |
| دفع الرسوم | يجب دفع الرسوم المقررة للتأشيرة |
| إجراء المقابلة | قد يتم إجراء مقابلة مع الأجنبي للتأكد من صحة البيانات المقدمة |
| التحقق الأمني | يتم التحقق من عدم وجود أي خطر أمني من منح التأشيرة للأجنبي |
| الموافقة النهائية | يتم منح التأشيرة بعد الحصول على الموافقة النهائية من الجهة المختصة |
```
